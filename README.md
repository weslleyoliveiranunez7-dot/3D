# Guerra dos Segundos Eternos — Protótipo v1.0

Jogo 3D cartoon para celular (HTML + CSS + JavaScript + Three.js por CDN, sem build).

## Publicar pelo celular
1. Abra github.com no navegador do celular e entre na conta.
2. Crie um repositório **público** chamado `guerra-dos-segundos-eternos`.
3. Envie (Add file > Upload files) ou crie os arquivos `index.html`, `style.css`, `game.js` e `README.md` na **raiz** do repositório.
4. Faça o commit.
5. Vá em **Settings > Pages**.
6. Em *Build and deployment*, escolha **Deploy from a branch**.
7. Selecione a branch **main** e a pasta **/(root)**, e salve.
8. Aguarde 1–2 minutos: o endereço só aparece depois de ativar o Pages.
9. Abra o link no Chrome do Android. Se der erro, atualize a página e confira os nomes dos arquivos.

## Testes manuais
- A tela inicial abre e mostra JOGAR, CONTROLES, SOBRE.
- Os 5 heróis aparecem na seleção; escolha um e toque em COMEÇAR MISSÃO.
- Joystick anda, arrastar à direita gira a câmera, PULO funciona.
- Letras coloridas trocam de herói sem reiniciar.
- Perto de cada terminal aparece a dica; PODER do herói certo ativa o terminal.
- Ativar os 3 terminais mostra a tela de conclusão.
- Pausa > CONTINUAR / VOLTAR AO INÍCIO funcionam.

## Limitações
- Sem colisão com prédio e árvores (só limites do mapa).
- Mula e Caracol têm poder (escudo visual / corrida rápida), mas a Missão 1 usa Star, Homem Elástico e Jimmy.
- Missão 2 (Blackstone / Ômega-01) ainda não existe.
- Personagens e cenário são formas simples provisórias.
